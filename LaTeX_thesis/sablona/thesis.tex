\abstract{%
% English abstract
This thesis presents a cross-subject Motor Imagery Brain-Computer Interface (BCI) pipeline applied to EEG data in the context of neurorehabilitation. A custom dataset class was implemented using the MOABB framework to load and preprocess multi-subject EEG recordings in BrainVision format. The preprocessing pipeline includes channel selection, bandpass filtering (8--30\,Hz), resampling, baseline correction, and epoch extraction. Cross-subject evaluation was performed using a Leave-One-Subject-Out scheme with five classification methods: Common Spatial Patterns (CSP) combined with Linear Discriminant Analysis (LDA), Logistic Regression (LR), and Support Vector Machine (SVM), as well as two deep learning architectures — EEGNet and ShallowConvNet. Experiments were conducted on both the custom dataset (29 subjects) and BCI Competition IV Dataset~2a (9 subjects). The best-performing method, CSP+LDA, achieved a mean accuracy of 67.4\,\% on the custom dataset and 74.2\,\% on BCI IV-2a. ShallowConvNet achieved competitive results (65.3\,\% and 72.5\,\%) with lower inter-subject variance than CSP+LDA.

\chapter{Introduction}
% =============================================================================

Motor imagery (MI) brain-computer interfaces (BCIs) offer a pathway for individuals with severe motor impairments to interact with assistive technology through imagined movement alone, without any physical output. By decoding the characteristic changes in sensorimotor EEG oscillations that accompany imagined limb movements, an MI-BCI can translate a user's intent into control commands for devices such as robotic exoskeletons, prosthetic limbs, or communication aids. This makes MI-BCIs a valuable tool in neurorehabilitation, where they can also promote neuroplasticity and support motor recovery.

A central challenge in deploying MI-BCIs is \textit{cross-subject generalisation}: EEG signals differ substantially between individuals, and a classifier trained on one group of users typically performs poorly when applied to a new user without a calibration session. Addressing this challenge requires robust evaluation protocols, diverse datasets, and classification methods that can extract subject-invariant features from EEG data.

A further practical challenge is the fragmented state of MI-BCI research software. Existing evaluation scripts are typically written for a single dataset and a single method, making it difficult to add new approaches, compare them fairly, or extend the evaluation to additional datasets without rewriting large portions of code. This fragmentation slows the iteration cycle and makes results hard to reproduce.

\textbf{This thesis addresses both challenges through the design and implementation of a configurable, extensible BCI evaluation pipeline.} The pipeline provides a unified framework for cross-subject evaluation of arbitrary classification methods across arbitrary EEG datasets. Methods and datasets are selected entirely through a YAML configuration file — no code changes are required to run a new combination. Classification methods are encapsulated as factory functions and registered by name; adding a new method requires implementing a single function and registering it in one place. Datasets are instantiated dynamically from dotted class paths, meaning any MOABB-compatible dataset can be added via configuration only. The pipeline handles paradigm parameter merging, result aggregation, CSV export, and visualisation automatically.

The pipeline is validated through a comprehensive cross-subject evaluation comparing five classification methods --- Common Spatial Patterns (CSP) combined with Linear Discriminant Analysis (LDA), Logistic Regression (LR), and Support Vector Machine (SVM) classifiers (denoted CSP+LDA, CSP+LR, and CSP+SVM), together with two deep learning architectures, EEGNet and ShallowConvNet --- on two datasets: a custom EEG dataset collected in the neuroinformatics laboratory at the Department of Computer Science and Engineering, University of West Bohemia, and the publicly available BCI Competition IV Dataset~2a. A transfer learning experiment investigates whether pretraining EEGNet on BCI IV-2a improves cross-subject accuracy on the custom dataset.

The thesis is structured as follows. Chapter~2 provides the theoretical background on BCIs, motor imagery, EEG signal processing, classical and deep learning classification methods, and cross-subject evaluation. Chapter~3 describes the datasets, the laboratory environment, a comparison of publicly available MI datasets, and the preprocessing pipeline. Chapter~4 describes the implemented methods and the pipeline architecture in detail. Chapter~5 presents the experimental results. Chapter~6 discusses the findings and limitations. Chapter~7 concludes the thesis.

% -----------------------------------------------------------------------------
\section{Brain-Computer Interfaces}
% -----------------------------------------------------------------------------

A brain-computer interface (BCI) is a system that establishes a direct communication channel between the brain and an external device, bypassing the body's conventional neuromuscular pathways~\cite{wolpaw2002brain}. Rather than relying on peripheral nerves or muscles, a BCI detects and interprets neural activity and translates it into commands that can control software, prosthetics, or rehabilitation devices. This makes BCIs particularly relevant for individuals with severe motor impairments caused by stroke, spinal cord injury, or neurodegenerative conditions such as ALS~\cite{yadav2025decoding}.

\subsection{Why EEG}

Several neuroimaging modalities can serve as the signal source for a BCI, including functional magnetic resonance imaging (fMRI), near-infrared spectroscopy (fNIRS), electrocorticography (ECoG), and electroencephalography (EEG). Among these, EEG has become the dominant choice for non-invasive BCI research due to its millisecond temporal resolution, low cost, portability, and absence of surgical risk~\cite{yadav2025decoding}. While fMRI offers superior spatial resolution, its low temporal resolution and requirement for large stationary equipment make it impractical for real-time BCI use. ECoG provides excellent signal quality but requires invasive electrode implantation. EEG thus represents the best practical trade-off between signal quality and usability.

\subsection{BCI Paradigms}

BCI paradigms define how the user interacts with the system to generate interpretable brain signals. They are broadly categorised into two classes based on the origin of the signal~\cite{yadav2025decoding}:

\begin{itemize}
    \item \textbf{Exogenous paradigms} rely on the brain's response to external stimuli. Steady-State Visual Evoked Potentials (SSVEP) exploit the visual cortex's response to flickering stimuli at specific frequencies. The P300 paradigm detects a positive deflection in the EEG signal approximately 300\,ms after a rare, attended stimulus.
    \item \textbf{Endogenous paradigms} are driven by internal mental activity without any external stimulus. Motor Imagery (MI) is the most widely used endogenous paradigm and forms the basis of this thesis.
\end{itemize}

% -----------------------------------------------------------------------------
\section{Motor Imagery}
% -----------------------------------------------------------------------------

Motor imagery (MI) refers to the mental simulation of a movement without any actual muscle activation or physical execution~\cite{yadav2025decoding}. When a person imagines moving a limb, the same sensorimotor cortex regions that would be active during real movement become engaged, producing measurable changes in the EEG signal.

\subsection{Neurophysiological Basis}

The neural correlate of MI is a phenomenon known as event-related desynchronisation and synchronisation (ERD/ERS), systematically reviewed by Pfurtscheller and Lopes da Silva~\cite{pfurtscheller1999event}. During imagined or real movement, oscillatory power in specific frequency bands decreases (ERD) over the contralateral motor cortex, followed by a power increase (ERS) after movement cessation. For MI-based BCIs, the relevant frequency bands are:

\begin{itemize}
    \item \textbf{Mu rhythm} (8--13\,Hz): generated by the sensorimotor cortex, strongly suppressed during MI.
    \item \textbf{Beta rhythm} (14--30\,Hz): also suppressed during MI, with a characteristic post-movement beta rebound.
\end{itemize}

Crucially, this activity is spatially lateralised. Left-hand MI produces ERD predominantly over the right hemisphere (electrode C4), while right-hand MI produces ERD over the left hemisphere (electrode C3). This hemispheric asymmetry is the fundamental signal that allows binary MI classification~\cite{pfurtscheller1999event}.

\subsection{Motor Imagery in Neurorehabilitation}

MI-BCIs have found a well-established role in neurorehabilitation, particularly for stroke and spinal cord injury patients. By coupling imagined movements with real-time feedback — via robotic exoskeletons or virtual reality — MI-BCIs can drive neuroplasticity and support motor recovery~\cite{yadav2025decoding}. The paradigm requires no external stimulation, making it applicable even for patients with sensory impairments. Its primary challenge is inter-subject variability: EEG patterns during MI differ substantially between individuals due to anatomical differences, varying cognitive strategies, and differences in MI ability.

% -----------------------------------------------------------------------------
\section{EEG Signal Processing}
% -----------------------------------------------------------------------------

Raw EEG recordings contain a mixture of neural activity, physiological artefacts (muscle and eye movements), and environmental noise. A preprocessing pipeline is required to isolate the signal components relevant for MI classification.

\subsection{Spatial Filtering and Channel Selection}

Full EEG caps may contain 32 to 256 electrodes, but for MI classification only the electrodes over the sensorimotor cortex are informative. The standard electrode set for binary left/right-hand MI consists of C3, C4, and Cz according to the international 10--20 system~\cite{klem1999ten}. C3 and C4 are positioned directly over the left and right motor cortices respectively, while Cz lies at the vertex. Restricting analysis to these three channels reduces dimensionality, computational cost, and the risk of overfitting.

\subsection{Temporal Filtering}

Bandpass filtering in the 8--30\,Hz range retains the mu and beta rhythms associated with MI while suppressing slow drifts (below 8\,Hz) and high-frequency noise and muscle artefacts (above 30\,Hz). In practice, a finite impulse response (FIR) or infinite impulse response (IIR) filter is applied to the continuous signal prior to epoching.

\subsection{Epoching and Baseline Correction}

An epoch is a time-locked segment of the continuous EEG signal extracted around an event marker. For each MI trial, an epoch spanning the pre-stimulus baseline through the movement period is extracted. Baseline correction removes slow voltage drifts by subtracting the mean amplitude of a pre-stimulus interval from the entire epoch, ensuring that subsequent features reflect event-related changes rather than absolute signal level.

% -----------------------------------------------------------------------------
\section{Common Spatial Patterns}
% -----------------------------------------------------------------------------

Common Spatial Patterns (CSP) is a supervised spatial filtering algorithm specifically designed for two-class EEG problems~\cite{blankertz2008optimizing}. Given labelled epochs from two classes, CSP learns a set of spatial filters — linear combinations of electrode signals — that simultaneously maximise the variance of one class while minimising the variance of the other.

Formally, CSP solves the generalised eigenvalue problem:
\begin{equation}
    \Sigma_1 \, \mathbf{w} = \lambda \, \Sigma_2 \, \mathbf{w},
\end{equation}
where $\Sigma_1$ and $\Sigma_2$ are the normalised spatial covariance matrices of the two classes and $\mathbf{w}$ is a spatial filter vector. The filters with the largest and smallest eigenvalues $\lambda$ are the most discriminative: they capture the channels and their combinations where the variance ratio between classes is maximised.

For each epoch, $n$ CSP filters are applied and the log-variance of the resulting filtered signals is computed:
\begin{equation}
    f_k = \log \left( \frac{\mathrm{var}(\mathbf{w}_k^\top \mathbf{x})}{\sum_j \mathrm{var}(\mathbf{w}_j^\top \mathbf{x})} \right),
\end{equation}
yielding a compact feature vector of $n$ values per epoch. The log transformation stabilises the variance and produces approximately Gaussian features. In this thesis the pipeline requests $n = 4$ CSP components; because the input is three-channel, MNE's implementation truncates the decomposition to the rank of the data, yielding three effective filters (see Section~\ref{sec:methods_csp}).

CSP is particularly well-suited to MI classification because the ERD/ERS patterns are inherently spatial: the discriminative information lies in which hemisphere shows power decrease, not in the raw amplitude of individual channels.

% -----------------------------------------------------------------------------
\section{Classification}
% -----------------------------------------------------------------------------

\subsection{Linear Discriminant Analysis}

Linear Discriminant Analysis (LDA) is the canonical classifier paired with CSP features~\cite{lotte2018review}. LDA models each class as a multivariate Gaussian distribution and assumes equal covariance across classes. The resulting decision boundary is the linear hyperplane that maximises the ratio of between-class scatter to within-class scatter. For CSP log-variance features, which are approximately Gaussian by construction, LDA's assumptions are well satisfied. LDA has no hyperparameters to tune, making it robust and reproducible — particularly important for cross-subject evaluation where training data per fold is limited.

\subsection{Logistic Regression and SVM}

Logistic Regression (LR) is a discriminative linear classifier that models the posterior class probability directly. Unlike LDA, it does not assume a generative Gaussian model, making it marginally more robust when the Gaussian assumption is violated. However, for the low-dimensional (4-feature) CSP output used here, LDA and LR produce nearly identical decision boundaries.

Support Vector Machines (SVM) with a radial basis function (RBF) kernel can model non-linear class boundaries in feature space. In principle, this additional flexibility could benefit subjects whose CSP features do not separate linearly. In practice, SVM performance on this dataset was lower than LDA, likely because the four-dimensional CSP feature space is already simple enough that the non-linear capacity confers no advantage, while the sensitivity to the regularisation parameter \texttt{C} and kernel width $\gamma$ introduces variance without tuning.

% -----------------------------------------------------------------------------
\section{Deep Learning Methods for EEG Classification}
% -----------------------------------------------------------------------------

Classical pipelines such as CSP+LDA extract hand-crafted spatial features and classify them with a linear model. Deep learning (DL) methods instead learn feature representations directly from raw or minimally preprocessed EEG epochs, removing the need to specify which features to compute. For EEG data the challenge is designing architectures that can exploit the specific structure of the signal — spatial relationships between electrodes, narrow-band spectral content, and temporal dynamics — while remaining trainable from relatively small datasets.

\subsection{EEGNet}

EEGNet~\cite{lawhern2018eegnet} is a compact convolutional neural network designed to be a general-purpose EEG classifier. Its design explicitly encodes the two main dimensions of EEG data — time and space — using two successive convolutional operations, making it interpretable and data-efficient compared to general-purpose deep networks.

The architecture consists of three stages:

\begin{enumerate}
    \item \textbf{Temporal convolution.} A set of 1-D filters of length $\lfloor \text{sfreq}/2 \rfloor$ is convolved along the time axis across all channels simultaneously. This layer learns band-specific temporal filters analogous to a learned bandpass filter bank.
    \item \textbf{Depthwise spatial convolution.} A depthwise convolution of kernel size $(C, 1)$ — where $C$ is the number of channels — learns a spatial filter across channels for each temporal filter output. These spatial filters play a similar role to CSP, i.e., they extract discriminative spatial patterns from the EEG signal, here applied independently to every band-specific temporal feature map. Batch normalisation and ELU activation follow, and an average pooling layer reduces temporal resolution.
    \item \textbf{Separable convolution.} A pointwise convolution summarises the spatial-temporal feature maps, followed by another pooling stage and dropout for regularisation.
\end{enumerate}

The final feature vector is passed to a dense output layer with log-softmax activation (paired with a negative log-likelihood loss during training). For the two-class, three-channel, 1501-sample configuration used in this thesis, the network contains 2\,658 trainable parameters, making it well-suited for small EEG datasets. EEGNet has been validated across multiple BCI paradigms — P300, ERN, MRCP, and motor imagery (sensorimotor rhythms) — and consistently outperforms or matches paradigm-specific architectures on standard benchmarks~\cite{lawhern2018eegnet}. It has subsequently been adapted for SSVEP classification~\cite{waytowich2018compactcnn}.

\subsection{ShallowConvNet}

ShallowConvNet (also referred to as ShallowFBCSPNet) was introduced by Schirrmeister et al.~\cite{schirrmeister2017deep} as a neural network analogue of the Filter Bank Common Spatial Patterns (FBCSP) pipeline. Its architecture is deliberately shallow — only two learned convolutional layers — and each layer has a direct correspondence to a step in the classical FBCSP processing chain, making the network highly interpretable.

The processing stages are as follows:

\begin{enumerate}
    \item \textbf{Temporal convolution.} A bank of 40 filters of length 25 samples is convolved along the time axis. These filters learn narrow-band spectral responses, analogous to the bandpass filters in FBCSP.
    \item \textbf{Spatial convolution.} A second convolution of kernel size $(C, 1)$ operates across channels for each temporal filter. This layer learns spatial projections of the band-filtered signal — the direct equivalent of the CSP spatial filters in FBCSP.
    \item \textbf{Squaring and mean pooling.} The element-wise square of the feature maps is computed, followed by average pooling over a large temporal window. Together, these operations approximate the instantaneous band-power envelope of each spatially filtered component, which is the feature computed by FBCSP before classification.
    \item \textbf{Logarithm activation.} A log transform is applied, matching the log-variance normalisation used in CSP feature extraction. The result is a compact feature vector per epoch.
\end{enumerate}

A linear classification layer with log-softmax activation follows. For the two-class, three-channel, 1501-sample configuration used in this thesis, the network contains 13\,442 trainable parameters. Because its inductive bias exactly matches the known signal structure of MI — band-power changes in spatially localised patterns — ShallowConvNet requires less data than EEGNet to learn useful representations, and performs competitively with CSP+LDA in cross-subject settings.

\subsection{Transformer-Based Architectures}

Transformer models, originally proposed for natural language processing, have more recently been applied to EEG classification~\cite{yadav2025decoding}. The self-attention mechanism allows transformers to model long-range temporal dependencies in the signal and learn flexible inter-channel relationships without imposing a fixed spatial filter structure. The most prominent example for motor imagery is EEG-Conformer~\cite{song2022conformer}, which is briefly described below as a representative of the transformer family considered for this thesis.

EEG-Conformer is a hybrid architecture that combines a shallow convolutional encoder with a transformer-based sequence model. The convolutional stage closely mirrors the front end of ShallowConvNet: a temporal convolution with a bank of approximately forty filters of length around twenty-five samples is applied along the time axis, followed by a spatial convolution across the input channels and an average-pooling operation that approximates the band-power envelope of each spatially filtered component. The output is then reshaped into a sequence of feature vectors --- one per pooled time step --- on which the transformer stage operates. The transformer stage consists of several encoder blocks, each containing multi-head self-attention, feed-forward sublayers, residual connections, and layer normalisation; positional encodings are added to the input sequence to preserve temporal ordering. A small fully connected classification head produces the final class scores. The convolutional front end therefore provides the inductive bias required to extract band-power-like features, while the transformer stage captures longer-range temporal structure that purely convolutional architectures must approximate via stacked receptive fields. Song et al.\ report state-of-the-art accuracy on standard MI benchmarks including BCI Competition IV Dataset~2a, consistently exceeding EEGNet and ShallowConvNet under subject-dependent evaluation.

The primary limitation of transformer models in EEG settings is their parameter count, which is roughly an order of magnitude larger than that of EEGNet or ShallowConvNet at comparable input sizes and which requires substantial training data to avoid overfitting. In cross-subject scenarios with small per-subject trial counts --- such as the custom dataset used in this thesis --- transformers are prone to underfitting or unstable training unless a large public dataset is available for pretraining~\cite{song2022conformer}. For this reason, transformer architectures are identified as a promising direction for future work, particularly as the volume of openly available EEG data continues to grow and as transfer-learning recipes for EEG matures~\cite{wu2022transfer,wan2021review}, but are not included in the experimental comparison of this thesis.

\section{Cross-Subject Evaluation}
% -----------------------------------------------------------------------------

\subsection{Inter-Subject Variability}

A fundamental challenge in EEG-based BCIs is that neural signals differ substantially between individuals. Sources of variability include inconsistent electrode placement, variations in brain state, individual differences in mental strategy, and temporal brain dynamics, all of which compromise model generalisability across users~\cite{yadav2025decoding}. As a result, a classifier trained on one subject typically performs poorly when applied to another without retraining or calibration.

\subsection{Leave-One-Subject-Out Evaluation}

Cross-subject evaluation aims to assess how well a model generalises to a previously unseen user. The standard protocol is Leave-One-Subject-Out (LOSO) cross-validation: given $N$ subjects, the model is trained on $N-1$ subjects and evaluated on the remaining subject. This is repeated for each subject and the mean accuracy across all $N$ folds is reported. The MOABB framework provides a standardised \texttt{CrossSubjectEvaluation} class that implements this protocol~\cite{jayaram2018moabb}.

LOSO directly answers the question relevant to calibration-free BCI deployment: \textit{can a model trained on a population of users decode motor imagery for a new, unseen user without any calibration data?} It is a pessimistic estimate — in practice, even a small number of calibration trials from the new user would improve accuracy — but it represents the most realistic and stringent evaluation scenario.

% -----------------------------------------------------------------------------
\section{Practical Limitations of BCI Systems}
% -----------------------------------------------------------------------------

Motor imagery BCIs face a set of fundamental challenges that affect both data quality and cross-subject generalisation. This thesis addresses several of these challenges directly: artefact contamination is mitigated through bandpass filtering; inter-subject variability is the central problem targeted by the cross-subject evaluation and transfer learning investigation described in subsequent chapters.

\subsection{Signal Artifacts and Noise}

EEG recordings are susceptible to several categories of contamination. \textbf{Electromyographic (EMG) artefacts} arise from facial and neck muscle contractions and produce broadband high-frequency noise that can overwhelm weak cortical signals. \textbf{Electrooculographic (EOG) artefacts} caused by eye movements and blinks introduce large-amplitude deflections that spread across frontal electrodes and propagate to motor cortex recordings via volume conduction. \textbf{Power-line noise} at 50\,Hz couples into recordings through impedance mismatches at the electrode-skin interface. \textbf{Electrode drift} refers to slow DC shifts caused by sweat accumulation or changes in skin impedance during a session, which can destabilise baseline correction and classification.

Standard mitigation strategies include bandpass filtering to suppress out-of-band noise, independent component analysis (ICA) to separate artefact components from neural sources, and notch filtering to remove power-line interference~\cite{yadav2025decoding}. In this thesis, bandpass filtering (8--30\,Hz) is applied as the primary artefact mitigation strategy.

\subsection{Inter-Subject Variability and BCI Illiteracy}

Inter-subject variability is the primary bottleneck for cross-subject MI classification. Inconsistent electrode placement, variations in brain state, individual differences in imagery strategy, and temporal brain dynamics produce ERD/ERS patterns that differ substantially between users under similar task conditions~\cite{yadav2025decoding}. In this thesis, individual LOSO accuracy with CSP+LDA ranged from 0.174 to 1.000 across 29 subjects, illustrating the extent of this variability.

A subset of users show little or no detectable ERD/ERS modulation during motor imagery. These non-responders — sometimes termed \textit{BCI-illiterate} — cannot achieve reliable control with standard MI paradigms regardless of classifier choice~\cite{lee2019openbmi}. Addressing inter-subject variability and non-response is the central problem this thesis targets through LOSO cross-subject evaluation and transfer learning from a larger benchmark dataset.

\subsection{Non-Stationarity}

EEG signals are non-stationary: the statistical properties of the signal change over time within a session (due to fatigue, attention lapses, and electrode drift) and between sessions (due to day-to-day variation in mental state and electrode re-placement). A classifier calibrated in one session may require recalibration in subsequent sessions, imposing a per-session setup cost that limits practical usability. Adaptive algorithms that update the model incrementally during use without requiring explicit recalibration are an active area of research~\cite{lotte2018review}.

\subsection{Practical Deployment Constraints}

In clinical neurorehabilitation settings, several additional constraints apply. Electrode preparation using conductive gel to achieve low impedance can take 30--60 minutes and requires trained personnel, making daily use impractical for many patients. Dry electrode systems reduce preparation time but typically exhibit higher noise levels. Long-term wear causes scalp irritation. Finally, the cognitive demand of motor imagery varies with user fatigue and motivation, introducing session-to-session variability that is difficult to model statistically and compounds the non-stationarity problem described above.

\section{MOABB Framework}
% -----------------------------------------------------------------------------

The Mother of All BCI Benchmarks (MOABB) is an open-source Python framework for reproducible evaluation of BCI algorithms~\cite{jayaram2018moabb}. It provides standardised data loading, preprocessing pipelines, and evaluation protocols across a large collection of public EEG datasets, enabling fair comparison between methods.

For this thesis, MOABB's \texttt{Cross\allowbreak Subject\allowbreak Evaluation} class implements the LOSO protocol, handling epoch extraction, train/test splitting, and result aggregation in a consistent manner. The \texttt{MotorImagery} paradigm class applies bandpass filtering, baseline correction, and event-locked epoching according to a unified interface. By building on MOABB, the pipeline presented in this thesis is directly comparable to results reported for other methods on standard benchmark datasets.

\section{Laboratory Environment}
% -----------------------------------------------------------------------------

The EEG data used in this thesis were collected in the neuroinformatics laboratory of the Department of Computer Science and Engineering (KIV), Faculty of Applied Sciences, University of West Bohemia in Pilsen. The laboratory is a dedicated academic research facility specialising in brain-computer interface research and medical informatics, and has been the site of several successive EEG measurement campaigns involving both the design of recording protocols and the development of signal processing and classification methods.

\subsection{Technical Equipment}

EEG signals were recorded using the \textbf{BrainProducts V-AMP~16} amplifier, a 16-channel portable amplifier designed for research-grade EEG acquisition. Signals were digitised and stored using \textbf{BrainVision Recorder} software in BrainVision format (three-file structure: \texttt{.eeg}, \texttt{.vhdr}, \texttt{.vmrk}). Electrodes were positioned according to the international 10--20 system using an EEG cap with conductive gel applied at each electrode site to ensure low skin-electrode impedance and signal quality.

For a subset of participants, the recording setup was extended with a \textbf{rehabilitation robot} used as an external exercise device. The robot generated synchronisation markers that were injected directly into the EEG recording stream, enabling precise time-locking of movement events to the neural signal. This setup reflects the applied neurorehabilitation context motivating the data collection: the long-term goal is to develop BCI systems that can be used in conjunction with robotic rehabilitation devices for motor recovery.

\subsection{Experimental Staff and Subjects}

All measurement sessions were conducted with the assistance of a trained nurse, who supervised correct EEG cap placement, verified electrode impedances, and monitored participant comfort throughout the session. This level of oversight is standard practice in clinical-grade EEG recording and contributes to the consistency of data quality across sessions.

A total of 29 healthy volunteers (aged 19--25 years) participated across all recording sessions conducted between 2020 and 2023. Participants were seated comfortably in front of a monitor and instructed to perform left-hand or right-hand motor imagery according to visual or LED cues. No financial compensation was provided; participants were recruited on a voluntary basis from the university community.

\section{Custom Motor Imagery Dataset}
% -----------------------------------------------------------------------------

The custom dataset used in this thesis consists of EEG recordings collected from 29 subjects performing motor imagery tasks. The recordings span multiple sessions conducted between 2020 and 2023 and originate from two distinct experimental protocols, referred to here as the Mochura and Saleh formats, reflecting differences in the recording setup and file naming conventions.

\subsection{Recording Equipment and Format}

All recordings were acquired using the BrainProducts V-AMP 16 amplifier and stored in BrainVision format, which consists of three files per recording: a binary data file (\texttt{.eeg}), a header file (\texttt{.vhdr}) containing channel and acquisition metadata, and a marker file (\texttt{.vmrk}) containing timestamped event annotations. Each recording session is stored in a date-named folder (\texttt{DD\_MM\_YYYY}).

The raw recordings contain 18 EEG channels sampled at either 500\,Hz (Mochura protocol) or 1000\,Hz (Saleh protocol).

\subsection{Recording Protocols}

\textbf{Mochura protocol.} The majority of subjects were recorded under a standard MI paradigm. Files follow the naming convention \texttt{<ID><gender><date><task><run>}, for example \texttt{1z01122020lh1} denotes subject~1, female, recorded on 01/12/2020, left-hand MI, run~1. Each subject has separate files for left-hand (\texttt{lh}) and right-hand (\texttt{rh}) runs, with some subjects having two runs per hand.

\textbf{Saleh protocol.} A subset of subjects was recorded with an additional haptic feedback component. Files follow the convention \texttt{HR\_<date>\_\allowbreak<ID>\_\allowbreak<condition>\_\allowbreak<side>}, where \texttt{condition} indicates whether vibrotactile stimulation was present and \texttt{side} encodes the hand (\texttt{leva} = left, \texttt{prava} = right). For the purposes of this thesis, the haptic condition is not used as a classification variable; left and right recordings are treated equivalently to those from the Mochura protocol.

\subsection{Experimental Paradigm}

Each recording consists of alternating rest and movement phases. The rest phase lasts 10 seconds and is initiated by an LED cue (Event~1). The mid-rest marker (Event~2) is placed 5 seconds after the start of rest and serves as the reference point for rest epoch extraction. The movement phase follows and spans 20 seconds. Event~5 marks the first detected force onset (first movement), and Event~4 marks subsequent movements within the same phase.

Importantly, Event~5 is absent in many files. In such cases, the first Event~4 occurring after the most recent Event~2 is used as the movement onset, provided no Event~5 preceded it within the same phase. This fallback logic is applied consistently across all recordings.

\subsection{Subject Identification}

Subject IDs are only unique within a single recording date, not globally. To ensure globally unique identifiers, a composite key combining the recording date and the original subject ID is used. For Mochura-format files the key has the form \texttt{DDMMYYYY\_ID} (e.g., \texttt{01122020\_1}); for Saleh-format files an additional \texttt{saleh\_} prefix is inserted (e.g., \texttt{01122020\_saleh\_1}) to prevent collisions with Mochura subjects sharing the same numeric ID. This scheme produces 29 unique subjects across all recording sessions.

\subsection{Classification Task}

The thesis addresses binary motor imagery classification: left-hand MI versus right-hand MI. The class of each epoch is determined solely by the filename (\texttt{lh} or \texttt{rh}), not by event codes, since both hands share the same event marker values within their respective files. Rest epochs are not used in the final classification pipeline.

\section{BCI Competition IV Dataset 2a}
% -----------------------------------------------------------------------------

The BCI Competition IV Dataset~2a~\cite{brunner2008bci} is a widely used public benchmark for motor imagery classification, made available through the fourth BCI Competition and accessible via the MOABB framework as \texttt{BNCI2014\_001}. It is used in this thesis as a source domain for transfer learning and as an independent evaluation benchmark.

\subsection{Recording Setup}

EEG was recorded from 9 healthy subjects using 22 electrodes placed according to the international 10--20 system, supplemented by 3 monopolar EOG channels for artefact monitoring. Signals were sampled at 250\,Hz and band-pass filtered between 0.5 and 100\,Hz online during acquisition.

\subsection{Experimental Paradigm}

The paradigm is cue-based. Each trial begins with a 2-second fixation period, followed by an auditory warning tone at $t = 0$\,s. At $t = 2$\,s, a directional arrow cue indicates the class to be imagined. Subjects perform motor imagery for 4 seconds (until $t = 6$\,s), after which a short rest period follows before the next trial. The dataset contains four motor imagery classes: left hand, right hand, feet, and tongue. Each subject completed two recording sessions on separate days. Each session consists of 6 runs of 48 trials, yielding 288 trials per session and 576 trials per subject across both sessions (144 trials per class per subject).

\subsection{Usage in this Thesis}

Only the left-hand and right-hand classes are used, matching the binary classification task of the custom dataset. To align the two datasets for transfer learning, channels are restricted to C3, C4, and Cz and recordings are resampled from 250\,Hz to 500\,Hz. The epoch window is set to $+0.5$\,s to $+3.5$\,s relative to cue onset, capturing the 3-second active MI period and matching the epoch duration of the custom dataset.

It must be acknowledged that, although both windows span the same 3\,s and yield the same input dimensionality of $1501$ samples, they are anchored to different events in the trial structure. The BCI IV-2a window is taken \emph{after} the visual cue and covers the post-cue preparatory and execution phase of motor imagery, whereas the custom-dataset window ends just \emph{before} the actual movement onset and therefore captures the pre-movement imagery interval. This temporal mis-alignment is a deliberate consequence of the differing trial protocols: BCI IV-2a is cue-locked, while the custom dataset is movement-locked and the active MI is most reliably localised before the marker. The two intervals therefore represent slightly different phases of the motor imagery process and constitute a known source of domain shift between the two datasets. This difference is taken into account when interpreting the transfer-learning results in Chapter~5: any benefit observed from BCI IV-2a pretraining is achieved \emph{despite}, not because of, this difference in trial structure.

\subsection{Suitability for Pretraining and Fine-Tuning}

Not all datasets are equally suitable as a source domain for pretraining. The following factors were considered:

\textbf{Subject count.} Pretraining benefits most from a large and diverse subject pool, as the model must learn representations that generalise across individuals. OpenBMI (54 subjects) and Cho2017 (52 subjects) offer the largest pools. BCI IV-2a has only 9 subjects but is highly controlled and widely cited as a benchmark.

\textbf{Trials per class.} A sufficient number of trials per subject is necessary to train deep learning models reliably. BCI IV-2a provides 144 trials per class per subject — the highest among candidates — making it the most data-rich option on a per-subject basis despite its small subject pool.

\textbf{Channel compatibility.} Since the custom dataset uses only C3, C4, and Cz, the source dataset must contain these electrodes. All candidates include these three positions in the 10--20 system and can be reduced to the same three-channel configuration.

\textbf{Task compatibility.} The custom dataset uses binary left/right hand MI. Datasets with additional classes (BCI IV-2a) can be subsetted to the two relevant classes, but the presence of other classes during pretraining introduces additional structure that may or may not transfer beneficially.

\textbf{MOABB availability.} All five public datasets are available through the MOABB framework, enabling standardised loading, preprocessing, and evaluation without dataset-specific code.

\subsection{Selection for this Thesis}

Based on the above analysis, \textbf{BCI Competition IV Dataset~2a} was selected as the pretraining source for the transfer learning experiments in this thesis. Despite having the fewest subjects (9), it provides the most trials per class per subject (144), is the most controlled and widely benchmarked MI dataset available, and has been used as the source domain in numerous transfer learning studies. Its controlled paradigm (fixed cue, clear epoch boundaries) also minimises domain shift relative to custom datasets.

The same preprocessing pipeline is applied to both datasets before epoch extraction. For the custom dataset, the raw-level steps (channel selection, resampling, bandpass filtering) are implemented within a custom MOABB dataset class at \texttt{Raw}-object creation, while epoch extraction and baseline correction are performed by MOABB's \texttt{MotorImagery} paradigm at evaluation time. For BCI Competition IV-2a, channel selection, resampling, bandpass filtering, and epoching are all handled by the MOABB paradigm. \subsection{Channel Selection}

Of the 18 recorded channels, only C3, C4, and Cz are retained. These three electrodes overlie the left motor cortex, right motor cortex, and vertex respectively, and capture the lateralised ERD/ERS patterns that are the basis of left/right hand MI classification. Discarding the remaining channels reduces dimensionality and avoids introducing irrelevant signal components.

\subsection{Resampling}

Saleh protocol recordings acquired at 1000\,Hz are downsampled to 500\,Hz to match the Mochura protocol. This ensures a uniform time axis and epoch length across all subjects. At 500\,Hz, the 4-second epoch window (tmin $= -3.5$\,s, tmax $= +0.5$\,s) yields 2001 samples per epoch per channel.

\subsection{Bandpass Filtering}

A bandpass filter with a passband of 8--30\,Hz is applied to the continuous signal after resampling. This retains the mu and beta rhythms associated with motor imagery while suppressing slow drifts below 8\,Hz and high-frequency noise and muscle artefacts above 30\,Hz. Filtering is performed on the continuous raw signal prior to epoching to avoid edge effects at epoch boundaries.

\subsection{Epoch Extraction and Baseline Correction}

Epochs are extracted in a window of $-3.5$\,s to $+0.5$\,s relative to each movement onset marker. The pre-stimulus interval from $-3.5$\,s to $-3.0$\,s serves as the baseline: its mean is subtracted from the entire epoch for each channel, removing residual slow voltage offsets and making epoch amplitudes comparable across trials and subjects.

Each recording contributes approximately 20 epochs per class per run. Across all 29 subjects, the dataset yields a total of approximately 1490 left-hand and 1620 right-hand epochs.

\subsection{MOABB Integration}

The preprocessing pipeline is encapsulated in a custom subclass of MOABB's \texttt{BaseDataset}, which implements the \texttt{\_get\_\allowbreak single\_\allowbreak subject\_\allowbreak data} interface. On each call, the class locates all \texttt{.vhdr} files belonging to the requested subject using the composite ID scheme, applies the full preprocessing pipeline, maps event markers to class annotations, and returns the preprocessed \texttt{Raw} objects organised by session and run. This design allows MOABB's \texttt{Cross\allowbreak Subject\allowbreak Evaluation} to handle epoch extraction and train/test splitting in a fully standardised manner.

\section{Classical Pipeline: CSP with Linear Classifiers}
\label{sec:methods_csp}
% -----------------------------------------------------------------------------

The classical baseline pipeline follows the standard approach for binary MI classification: Common Spatial Patterns (CSP) for spatial feature extraction followed by a linear classifier. As described in Section~2.4, CSP learns spatial filters that maximise variance ratio between classes; each epoch is projected through these filters and the log-variance of the filtered signals forms the feature vector.

\textbf{Number of CSP components.} The pipeline requests four CSP components (\texttt{n\_components}~=~4 in \texttt{config/dataset\_config.yaml}). Because the input has only three channels, the class-conditional covariance matrices have rank at most three, and MNE's \texttt{CSP} implementation automatically truncates the spatial decomposition to \texttt{min(n\_components, rank)}~=~3 filters. Each epoch is therefore projected onto three spatial filters, yielding a three-dimensional log-variance feature vector — the full spatial decomposition available for this channel configuration. The value four is retained in the configuration so that the same YAML can be used unchanged when the pipeline is applied to datasets with more channels.

\textbf{Classifiers.} Three classifiers are evaluated on top of CSP features: Linear Discriminant Analysis (LDA), Logistic Regression (LR), and Support Vector Machine (SVM) with an RBF kernel. LDA is the primary baseline due to its strong theoretical fit with CSP log-variance features and absence of hyperparameters. LR and SVM are included for comparison. All three classifiers are used with sklearn's default hyperparameters, with two exceptions that do not constitute hyperparameter tuning: LR and SVM are preceded by a \texttt{StandardScaler} to match the expected input scale of those classifiers, and \texttt{LogisticRegression} is configured with \texttt{max\_iter=1000} to ensure convergence on all folds. No hyperparameter search is performed, consistent with the cross-subject evaluation setting where per-fold training data is limited.

\section{Deep Learning Methods}
% -----------------------------------------------------------------------------

\textbf{Epoch window for deep learning.} EEGNet, ShallowConvNet, and the transfer-learning experiments all use a 3-second active MI window of $-3.5$\,s to $-0.5$\,s relative to movement onset, narrower than the 4-second window used by CSP. The choice reflects two considerations.

First, the marker in the custom dataset is placed at the actual force onset, so the imagined movement precedes the marker. Restricting the input to the pre-onset interval excludes the moment of physical motion and the half-second immediately surrounding it, where movement-related artefacts and short-latency motor potentials may contaminate the signal. CSP's covariance-and-log-variance feature is dominated by sustained band-power changes and is comparatively tolerant of brief artefact contamination, so the broader 4-second dataset-default window is retained for the classical pipeline. The convolutional networks operate on raw time-series and are more sensitive to such contamination, motivating the tighter window.

Second, the BCI Competition IV Dataset~2a uses a cue-based protocol in which the active MI period is defined as $+0.5$\,s to $+3.5$\,s after cue onset (3\,s). Aligning the custom-dataset DL window to the same 3-second duration allows the same network architecture, with the same input dimensionality of $1501$ samples, to be pretrained on BCI IV-2a and evaluated on the custom dataset without modification. This alignment is required for the transfer-learning experiment in Section~\ref{sec:methods_tl} and is preserved across the standalone EEGNet and ShallowConvNet evaluations for consistency.

\subsection{EEGNet}

EEGNet~\cite{lawhern2018eegnet} is implemented using the braindecode library, which provides a scikit-learn-compatible \texttt{EEGClassifier} wrapper around the PyTorch module. This allows EEGNet to be integrated directly into the MOABB evaluation pipeline alongside the classical CSP pipelines.

\textbf{Architecture configuration.} The network is configured for $C = 3$ input channels (C3, C4, Cz), $T = 1501$ time samples (3\,s at 500\,Hz), and $N = 2$ output classes. The \texttt{final\_conv\_length} parameter is set to \texttt{'auto'}, allowing the network to infer the appropriate output size from the input dimensions.

\textbf{Training configuration.} The network is trained with the Adam optimiser using 300 epochs, learning rate $10^{-4}$, and batch size 64. These values are not the product of a systematic hyperparameter search: exhaustive tuning would risk leaking information from the held-out subject in a LOSO setting, and nested cross-validation across 29 subjects is computationally prohibitive given the per-fold training cost. Each value was instead chosen on principled grounds. The 300-epoch budget pairs with the LOSO training pool of approximately 3000 epochs from 28 subjects: given the network's modest parameter count of 2658, this budget is well below the overfitting threshold and is consistent with the order of magnitude used for EEGNet in the original paper~\cite{lawhern2018eegnet} and in subsequent braindecode tutorials. The learning rate of $10^{-4}$ is one order of magnitude below the Adam default; a conservative rate suits a small network on a low-channel input, where the optimisation landscape is sensitive to large updates, and matches the order of magnitude commonly used for compact EEG CNNs. A batch size of 64 is a standard choice in the EEG CNN literature, fits comfortably in GPU memory for the $3 \times 1501$ input, and provides a reasonable trade-off between gradient stability and stochastic exploration. All three values are exposed in \texttt{config/dataset\allowbreak\_\allowbreak config.yaml} and can be overridden per-run via \texttt{pipeline.yaml}. No validation split is used during LOSO training; the full training set (all subjects except the held-out test subject) is used for each fold. Input data is cast to \texttt{float32} before passing to the network, as MOABB returns \texttt{float64} arrays. The shared deep-learning epoch window described above is used.

\subsection{ShallowConvNet}

ShallowConvNet~\cite{schirrmeister2017deep} is implemented identically to EEGNet via braindecode's \texttt{ShallowFBCSPNet} module, using the same \texttt{EEGClassifier} wrapper and training infrastructure.

\textbf{Architecture configuration.} The network is configured for the same $C = 3$, $T = 1501$, $N = 2$ settings as EEGNet, with \texttt{final\_conv\_length='auto'}.

\textbf{Training configuration.} The same default hyperparameters and epoch window as EEGNet are used: 300 epochs, learning rate $10^{-4}$, batch size 64.

\section{Transfer Learning}
\label{sec:methods_tl}
% -----------------------------------------------------------------------------

Transfer learning is evaluated as an extension of EEGNet to assess whether pretraining on a larger public dataset improves cross-subject performance on the custom dataset. Transfer learning has been studied extensively in the EEG-BCI context as a means of mitigating inter-subject and inter-session variability without per-user calibration; the recent reviews by~\cite{wu2022transfer} and~\cite{wan2021review} survey the main families of approaches, ranging from feature alignment and Riemannian geometry to deep pretraining and domain adaptation. The experiment in this thesis follows the simplest of these strategies, a standard pretrain-then-adapt paradigm with end-to-end fine-tuning, leaving more sophisticated alignment techniques as future work.

\textbf{Pretraining.} EEGNet is pretrained on the full BCI Competition IV Dataset~2a (all 9 subjects, both sessions, left-hand and right-hand classes only). Pretraining uses the same hyperparameters as the standalone EEGNet evaluation (300 epochs, lr\,$= 10^{-4}$, batch size 64). The resulting weights are stored in memory and loaded into a fresh \texttt{EEGClassifier} at the start of each LOSO fold.

\textbf{LOSO evaluation.} The pretrained model is evaluated on the custom dataset using LOSO cross-validation. For each fold (one test subject held out), three conditions are compared within the same script and the same LOSO partitioning:

\begin{itemize}
    \item \textbf{Custom-only.} A fresh EEGNet is trained from scratch on the custom training subjects (all except the held-out test subject) for 300 epochs at lr\,$=10^{-4}$, identical to the standalone EEGNet pipeline. This serves as the from-scratch baseline for the comparison and is computed inside the transfer-learning script rather than reused from the main pipeline run, to ensure that all three conditions share the same data partitioning, the same training framework, and the same random initialisation regime.
    \item \textbf{Direct transfer.} The pretrained model is applied to the test subject without any weight updates. This measures the zero-shot cross-dataset generalisation of the pretrained representations.
    \item \textbf{Fine-tuning.} The pretrained model is fine-tuned on the custom training subjects (all except the held-out test subject) for 100 epochs at a learning rate of $10^{-5}$, ten times lower than the pretraining rate. The reduced learning rate is used to preserve the pretrained representations while adapting to the custom dataset distribution.
\end{itemize}

\textbf{Reproducibility.} Before each fresh classifier instantiation (pretraining, custom-only, and fine-tuning) the PyTorch and NumPy random number generators are reset to a fixed seed (\texttt{SEED}~$=42$). This guarantees that the three conditions in each LOSO fold start from identical initialisation states and that the entire evaluation is reproducible run-to-run.

\textbf{Epoch alignment.} The BCI IV-2a epoch window ($+0.5$\,s to $+3.5$\,s relative to cue) and the custom dataset window ($-3.5$\,s to $-0.5$\,s relative to movement onset) both span 3\,s. At 500\,Hz, BCI IV-2a epochs contain 1502 samples after resampling; one sample is trimmed to match the custom dataset's 1501 samples.

\section{Configurable Evaluation Pipeline}
% -----------------------------------------------------------------------------

A primary contribution of this thesis is the design and implementation of a configurable, extensible pipeline for cross-subject BCI evaluation. The pipeline decouples the selection of datasets and classification methods from the evaluation logic, allowing arbitrary combinations to be run by editing a single YAML configuration file without any code changes.

\subsection{Design Goals}

The pipeline was designed to address three practical limitations of typical BCI evaluation codebases:

\begin{enumerate}
    \item \textbf{Method fragmentation.} Individual evaluation scripts are tightly coupled to a specific method. Adding a new classifier requires duplicating the evaluation boilerplate. The pipeline solves this by separating method definition from evaluation execution.
    \item \textbf{Dataset fragmentation.} Loading different datasets typically requires dataset-specific code. The pipeline solves this by instantiating datasets dynamically from dotted class paths, so any MOABB-compatible dataset can be added through configuration alone.
    \item \textbf{Reproducibility.} Results are saved to timestamped CSV files and plots are generated automatically, ensuring each run is independently archived.
\end{enumerate}

\subsection{Registry Pattern}

Each classification method is implemented as a \textit{factory function} with the signature:

\begin{verbatim}
def build_method(config: dict, params: dict)
        -> tuple[Pipeline, dict]
\end{verbatim}

The function receives the full \texttt{dataset\_config.yaml} as \texttt{config} and any per-run hyperparameter overrides as \texttt{params}. It returns a scikit-learn \texttt{Pipeline} and a dictionary of paradigm parameter overrides (e.g., the epoch window required by deep learning methods). All factory functions are registered by name in a central \texttt{REGISTRY} dictionary in \texttt{methods/\_\_init\_\_.py}. The evaluation loop retrieves methods by name and never needs to know their implementation details.

Adding a new classification method requires three steps: implementing the factory function in a new file, adding two lines to the registry, and listing the method name in \texttt{pipeline.yaml}. The evaluation loop itself does not change.

\subsection{Dynamic Dataset Instantiation}

Datasets are specified in \texttt{pipeline.yaml} as dotted Python class paths, for example:

\begin{verbatim}
class: moabb.datasets.BNCI2014_001
\end{verbatim}

The pipeline uses Python's \texttt{importlib} to import and instantiate the class at runtime. Constructor arguments and paradigm parameter overrides are also specified in the configuration file. This means any MOABB dataset — or any custom class that implements the MOABB \texttt{BaseDataset} interface — can be added without code modifications. The custom dataset developed in this thesis is integrated in exactly the same way as a standard MOABB dataset.

\subsection{Paradigm Merging}

Different methods and datasets may require different epoch windows or preprocessing parameters. The pipeline resolves this through a three-level merge:

\begin{enumerate}
    \item \textbf{Base parameters} from \texttt{dataset\_config.yaml} (sampling rate, filter, baseline).
    \item \textbf{Method overrides} from the factory function (e.g., DL methods specify the active MI epoch window).
    \item \textbf{Dataset overrides} from \texttt{pipeline.yaml} (e.g., BCI IV-2a specifies its own \texttt{tmin}/\texttt{tmax}).
\end{enumerate}

Dataset overrides always take the highest priority, ensuring that dataset-specific requirements such as timing or channel configuration are respected regardless of the method being evaluated.

\subsection{Configuration File}

All runtime decisions are controlled through \texttt{config/pipeline.yaml}. A minimal example selecting two methods on one dataset is shown below:

\begin{verbatim}
datasets:
  - name: custom
    class: dataset.custom_dataset.MotorImageryDataset
    init_params:
      data_path: "data/"
      config_path: "config/dataset_config.yaml"
    paradigm: {}

methods:
  - name: CSP+LDA
  - name: EEGNet
    params:
      max_epochs: 200
      lr: 0.0005
\end{verbatim}

Methods listed without a \texttt{params} block use the defaults from \texttt{dataset\_\allowbreak config.yaml}. Hyperparameters can be overridden per-method without affecting other methods or the evaluation logic.

\subsection{Evaluation Execution}

The entry point \texttt{run\_pipeline.py} reads both configuration files, instantiates all datasets and methods, and executes MOABB's \texttt{Cross\allowbreak Subject\allowbreak Evaluation} for each method--dataset combination. Results are aggregated across all combinations, printed as a summary table, and saved to a timestamped CSV file (\texttt{results/\allowbreak pipeline\_\allowbreak results\_\allowbreak YYYYMMDD\_\allowbreak HHMMSS\allowbreak.csv}). Two plots are generated automatically: a per-subject grouped bar chart and a summary bar chart with mean~$\pm$~std error bars. Transfer learning is executed as an optional post-processing step when enabled in the configuration.

% -----------------------------------------------------------------------------
\section{Evaluation Strategy}
% -----------------------------------------------------------------------------

\subsection{Leave-One-Subject-Out Cross-Validation}

All methods are evaluated using Leave-One-Subject-Out (LOSO) cross-validation via MOABB's \texttt{Cross\allowbreak Subject\allowbreak Evaluation} class. In each fold, one subject is held out as the test set and the remaining subjects form the training set. The classifier is trained from scratch (or fine-tuned, in the transfer learning condition) on each fold. Mean accuracy and standard deviation across all subjects are reported as the primary performance metrics.

\subsection{Datasets Used in Evaluation}

Two datasets are used in the experiments:

\begin{itemize}
    \item \textbf{Custom dataset} (29 subjects): primary evaluation target for all methods.
    \item \textbf{BCI Competition IV Dataset~2a} (9 subjects): pretraining source for transfer learning and independent benchmark for all methods.
\end{itemize}

\section{Transfer Learning}
% -----------------------------------------------------------------------------

Table~\ref{tab:results_tl} reports the transfer learning results on the custom dataset. Three conditions are compared: EEGNet trained from scratch on the custom training subjects (custom-only baseline), direct transfer of the model pretrained on BCI IV-2a without any weight updates, and fine-tuning of the pretrained model on the custom training subjects for each LOSO fold. All three conditions are evaluated within the same script (\texttt{evaluation/transfer\_learning.py}), use the same LOSO partitioning of subjects, and reset the PyTorch and NumPy random number generators to a fixed seed before each fresh classifier instantiation. Per-subject results are therefore strictly paired and the means and standard deviations reported below are directly comparable. The custom-only column in this table is computed by the same script and supersedes the EEGNet entry of Table~\ref{tab:results_custom} for the purposes of the transfer-learning comparison; the small numerical difference between the two arises from the different random seed used by the main pipeline run and is consistent with EEGNet's known sensitivity to initialisation in the low-channel, small-data regime.

\begin{table}[ht]
    \centering
    \caption{Transfer learning results on the custom dataset (29 subjects). All conditions use EEGNet. Chance level: 0.500.}
    \label{tab:results_tl}
    \begin{tabular}{lll}
        \hline
        \textbf{Condition} & \textbf{Mean accuracy} & \textbf{Std} \\
        \hline
        EEGNet custom-only  & 0.520 & 0.058 \\
        Direct transfer     & 0.531 & 0.073 \\
        Fine-tuned          & 0.515 & 0.050 \\
        \hline
        Chance              & 0.500 & —     \\
        \hline
    \end{tabular}
\end{table}

All three conditions cluster narrowly around chance level. Direct transfer (0.531) is the highest of the three but only $1.1$\,pp above the custom-only baseline (0.520) and $1.7$\,pp above fine-tuning (0.515). Pairwise Wilcoxon signed-rank tests on the 29 per-subject scores yield $p = 0.29$ (custom-only vs.\ direct), $p = 0.84$ (custom-only vs.\ fine-tuned), and $p = 0.25$ (direct vs.\ fine-tuned); none of the differences is statistically significant. The standard deviation does shrink monotonically along the adaptation path (0.058 $\rightarrow$ 0.073 $\rightarrow$ 0.050)\footnote{The non-monotone middle term (direct transfer, 0.073) reflects the wider spread that arises when an unaltered cross-dataset model is evaluated on subjects whose covariance structure differs from the BCI IV-2a population.}, with fine-tuning producing the most consistent (though still near-chance) per-subject predictions: its accuracy range $[0.42, 0.59]$ is the narrowest of the three.

Per-subject results reveal substantial heterogeneity even though the means are nearly equal. Some subjects benefit clearly from pretraining --- subject~5 rises from $0.400$ (custom-only) to $0.600$ (direct) and $0.575$ (fine-tuned), and subject~23 from $0.500$ to $0.642$ and $0.583$ --- while for others pretraining is harmful, most strikingly for subject~3 ($0.738$ custom-only collapses to $0.393$ direct and $0.459$ fine-tuned). This bidirectional sensitivity, rather than a uniform improvement, is the dominant pattern: the pretrained BCI IV-2a representations do not provide a reliable inductive bias for the custom dataset, likely due to the domain shift introduced by the different recording paradigm (cue-based vs.\ movement-onset-based epochs) and the very limited number of fine-tuning trials per subject (${\sim}54$ per class). A single fixed transfer strategy therefore cannot be expected to generalise consistently across the subject population~\cite{lotte2018review,wu2022transfer}.

\section{Interpretation of Results}
% -----------------------------------------------------------------------------

The cross-subject LOSO evaluation reveals a clear ordering among the tested approaches. CSP with LDA achieved the highest mean accuracy on both datasets (67.4\,\% on the custom dataset, 74.2\,\% on BCI IV-2a), while EEGNet remained near the chance level of 50\,\% on both. ShallowConvNet occupied an intermediate position (65.3\,\% and 72.5\,\%), competitive with CSP+LDA while exhibiting lower inter-subject variance. This ordering reflects fundamental differences between the method families in the low-channel, small-dataset regime of this thesis.

CSP is a domain-specific algorithm that explicitly maximises the variance ratio between classes by learning spatial filters tuned to the lateralised ERD/ERS structure of motor imagery. Given only three electrodes over the sensorimotor cortex, CSP extracts the most informative projections from the available spatial information. LDA then classifies three log-variance features (see Section~\ref{sec:methods_csp}) — a task that is well-conditioned even with limited training data. EEGNet, by contrast, learns convolutional features from raw epoch data. Although the network is compact by deep learning standards, it still requires sufficient data and channel diversity to learn subject-invariant representations~\cite{lawhern2018eegnet}. With three channels and approximately 54 trials per class per subject, the model cannot overcome high inter-subject variability in sensorimotor oscillations.

EEGNet's underperformance is consistent across both datasets: its mean accuracy on BCI IV-2a (53.5\,\%) is essentially identical to that on the custom dataset (53.6\,\%), despite BCI IV-2a offering nearly three times as many trials per subject. This rules out sample size as the dominant factor. A more likely explanation is architectural: EEGNet's depthwise spatial convolution learns one spatial filter per temporal filter and, with only three input channels, has at most three linearly independent spatial patterns to discover --- the same bottleneck under which CSP operates. EEGNet additionally lacks an explicit band-power or log-variance stage and must approximate these features through temporal pooling of squared activations implicit in its hidden layers. The architecture was originally validated on configurations with substantially larger channel counts (typically 22 or 64), where the depthwise-then-separable design has sufficient spatial diversity to exploit; the three-channel restriction used here removes that headroom and reduces EEGNet's effective expressiveness to roughly that of its single temporal filter bank. ShallowConvNet, by contrast, explicitly squares and log-transforms its activations to directly mirror the FBCSP feature extraction pipeline~\cite{schirrmeister2017deep}, which explains why it generalises competitively with CSP+LDA despite operating on the same three-channel input.

The lower inter-subject variance of ShallowConvNet relative to CSP+LDA (custom: $\sigma = 0.177$ vs.\ $0.218$; BCI IV-2a: $\sigma = 0.141$ vs.\ $0.156$) admits a similar architectural explanation. CSP fits a single set of spatial filters per fold by maximising a variance ratio over the pooled training subjects' covariance matrices: when the held-out subject's spatial covariance lies close to the training pool, the filters generalise well; when it deviates, the same filters can be markedly suboptimal, producing the wide CSP+LDA range observed in the custom dataset (0.174 to 1.000). ShallowConvNet, in contrast, learns a bank of forty temporal filters and the corresponding spatial patterns through stochastic optimisation over thousands of mini-batches drawn from the full training population. The result is an effective ensemble of learned band-power features whose averaging over diverse subjects partially compensates for any single subject's deviation, producing a tighter per-subject distribution. The same ordering --- ShallowConvNet variance below CSP+LDA variance --- holds on both datasets, although the gap is more pronounced on the custom dataset where between-subject heterogeneity is greater.

The transfer learning experiment was run as three paired conditions inside a single script (custom-only, direct transfer, fine-tuned), all sharing the same LOSO partitioning and a fixed random seed reset before each fresh classifier instantiation. Under this paired evaluation, pretraining on BCI IV-2a produces no statistically detectable improvement over training EEGNet from scratch on the custom dataset: direct transfer reaches a mean of $0.531$ versus $0.520$ for custom-only and $0.515$ for fine-tuning, and pairwise Wilcoxon signed-rank tests give $p \geq 0.25$ for all three pairs. The most informative pattern is in the standard deviation: fine-tuning narrows the per-subject score range from $[0.40, 0.74]$ (custom-only) to $[0.42, 0.59]$, suggesting that pretrained representations followed by short fine-tuning produce more consistent --- though still near-chance --- predictions, but at the cost of cancelling the few subjects on which the from-scratch network would have performed well. Per-subject heterogeneity remains high in both directions: some subjects gain markedly from pretraining while others lose accuracy by more than $30$\,pp. A single fixed transfer strategy therefore cannot consistently generalise across the subject population~\cite{lotte2018review,wu2022transfer}.

The CSP+LDA vs.\ CSP+LR difference is statistically detectable but vanishingly small in magnitude ($|\Delta|<\!0.002$), consistent with the theoretical expectation that LDA and LR produce near-identical decision boundaries on the low-dimensional CSP feature space.

% -----------------------------------------------------------------------------
\section{Clinical Interpretation}
% -----------------------------------------------------------------------------

The 67--74\,\% mean accuracy obtained with CSP+LDA on a held-out subject with zero calibration data is, in absolute terms, below the level commonly considered the lower bound for usable two-class BCI control (generally cited at around 70--75\,\% in the BCI literature). These numbers should be read in context: LOSO simulates the most pessimistic deployment scenario --- a new user for whom no calibration trials are available at all --- but the gap to clinical applicability is wider than this evaluation alone implies. Translating cross-subject classification on a laboratory dataset into a deployable neurorehabilitation tool would additionally require subject-specific calibration to lift accuracy above the control threshold, a closed-loop feedback paradigm with appropriate latency, online artefact handling, validation on the clinical population (rather than healthy participants in a controlled laboratory), and ethical and regulatory clearance. The contribution of this thesis is therefore methodological: a benchmark of calibration-free performance against which future subject-adaptive methods can be compared, and a tool for rapidly evaluating new classifiers on future recordings without rewriting evaluation code. It is not, in itself, a step towards a clinically deployable system.

% -----------------------------------------------------------------------------
\section{Limitations of the Implemented Pipeline}
% -----------------------------------------------------------------------------

The pipeline operates under several constraints that limit achievable accuracy.

\textbf{Channel restriction.} Limiting input to three electrodes is motivated by the spatial specificity of MI-related ERD/ERS, but it also prevents deep learning models from exploiting broader spatial patterns. EEGNet and similar architectures were benchmarked on full 64-channel recordings; with three channels their spatial filtering capacity is reduced to the same information available to CSP, removing the representational advantage of deep networks.

\textbf{Epoch alignment.} The custom dataset anchors epochs to force onset (MI precedes the marker), while BCI IV-2a uses a visual cue (MI follows the marker). The chosen epoch windows align the active MI periods as closely as possible, but differences in cognitive preparation between cue-based and detection-based paradigms introduce a cross-dataset domain shift that pretraining cannot fully compensate.

\textbf{Fine-tuning configuration.} A single configuration (100 epochs, lr $= 10^{-5}$) was evaluated. Layer-wise learning rate schedules, partial layer freezing, or broader hyperparameter search could improve the fine-tuned condition. However, the small size of the custom dataset limits adaptation without overfitting.

\chapter{Conclusion}
% =============================================================================

This thesis presented a configurable, extensible pipeline for cross-subject Motor Imagery BCI evaluation, together with a comprehensive experimental comparison of five classification methods on two EEG datasets.

\textbf{Pipeline.} The primary contribution is the evaluation pipeline itself. The registry-based architecture decouples method definitions from the evaluation loop: each classification method is a factory function registered by name, and datasets are instantiated dynamically from dotted class paths specified in a YAML configuration file. As a result, adding a new method requires implementing a single function and registering it in one place; adding a new dataset requires only a configuration entry with no code changes. The pipeline handles paradigm parameter merging, LOSO evaluation via MOABB, result aggregation, timestamped CSV export, and automatic plot generation. This design makes the experimental workflow reproducible, easy to extend, and directly applicable to future BCI research in the laboratory.

\textbf{Experimental results.} The evaluation on the custom dataset (29 subjects, LOSO) shows that CSP+LDA achieves the highest mean accuracy (67.4\,\%), followed by ShallowConvNet (65.3\,\%), CSP+SVM (63.1\,\%), and EEGNet (53.6\,\%). The same ordering holds on BCI Competition IV Dataset~2a, with higher overall accuracy on all methods (CSP+LDA 74.2\,\%, ShallowConvNet 72.5\,\%, EEGNet 53.5\,\%), consistent with the larger per-subject trial count in that dataset. ShallowConvNet is notable for achieving results close to CSP+LDA with lower inter-subject variance, suggesting more consistent generalisation across subjects. EEGNet consistently underperforms in both settings, reflecting the difficulty of learning subject-invariant representations from three-channel input with limited data.

\textbf{Transfer learning.} A paired evaluation with a fixed random seed shows that pretraining EEGNet on BCI IV-2a does not improve accuracy on the custom dataset over training from scratch: mean accuracies of $52.0$\,\% (custom-only), $53.1$\,\% (direct transfer), and $51.5$\,\% (fine-tuned) are statistically indistinguishable (paired Wilcoxon $p \geq 0.25$ for all three pairwise comparisons). Per-subject results show high bidirectional heterogeneity, with some subjects gaining markedly from pretraining while others lose accuracy by tens of percentage points. The main limiting factors are the domain shift between the two recording paradigms and the small number of fine-tuning trials available per subject.

\textbf{Reproducibility.} The pipeline is fully reproducible from the committed artefacts. All runtime choices — datasets, methods, hyperparameters, epoch windows, and output locations — are specified in two YAML files (\texttt{config/pipeline.yaml} and \texttt{config/dataset\_config.yaml}). Each execution of \texttt{run\_pipeline.py} writes a timestamped CSV of per-subject scores and saves the per-subject and summary plots automatically. The transfer-learning evaluation writes a separate timestamped CSV. Every numeric claim in Chapter~5 can therefore be re-derived by running the pipeline on the same data with the committed configuration files, and the generated CSVs are the single source of truth for the results tables and figures.

\textbf{Laboratory handover.} Because the pipeline treats datasets and methods as configuration rather than code, the neuroinformatics laboratory can apply it to future recordings by implementing a new MOABB-compatible dataset class (or selecting an existing MOABB dataset) and adding a single entry to \texttt{pipeline.yaml}. Adding a new classification method requires one Python file and two lines of registry code. This lowers the engineering cost of comparative BCI studies in the laboratory and is a concrete outcome beyond the experimental comparison reported here.

\textbf{Future work.} Several directions could extend this thesis. Expanding the electrode set beyond C3, C4, Cz would give deep learning models access to broader spatial patterns and may close the gap with classical methods. Transformer-based architectures, including EEG-Conformer~\cite{song2022conformer}, have shown strong results on larger EEG datasets and could be integrated into the pipeline as an additional registered method. Subject-adaptive fine-tuning strategies surveyed in~\cite{wu2022transfer,wan2021review} --- such as layer freezing, Euclidean alignment, meta-learning initialisation, or few-shot adaptation --- may improve transfer learning outcomes without requiring more data. Finally, the pipeline could be extended with additional public datasets from MOABB to provide a broader cross-dataset benchmark and strengthen the generalisability of the reported results.
